# بوت اغاني ديسكورد

بوت بسيط يشغل الاغاني من يوتيوب داخل الروم الصوتي عبر اوامر عربية وانجليزية.

## الاوامر المتوفرة

| الامر | الاختصارات | الوظيفة |
|---|---|---|
| play | p / شغل / ش | تشغيل اغنية (اسم او رابط) |
| skip | s / تخطي / خطي | الانتقال للمقطع التالي |
| pause | pa | ايقاف المقطع مؤقتا |
| resume | r / استمرار / كمل | استئناف التشغيل |
| stop | وقف | ايقاف التشغيل نهائيا وخروج البوت |
| volume | v / صوت / ص | تعديل او عرض مستوى الصوت (رقم من 0 الى 100) |
| nowplaying | np | عرض تفاصيل المقطع الحالي |
| loop | تكرار | تفعيل او تعطيل تكرار المقطع |

## خطوات التشغيل

### 1. انشاء البوت في ديسكورد
1. ادخل على https://discord.com/developers/applications
2. اضغط New Application واعطه اسم
3. من قسم Bot اضغط Add Bot
4. من نفس الصفحة فعّل خيار MESSAGE CONTENT INTENT (مهم جدا حتى تشتغل الاوامر)
5. انسخ التوكن (Token) من نفس الصفحة

### 2. دعوة البوت لسيرفرك
من قسم OAuth2 > URL Generator اختر:
- Scopes: bot
- Bot Permissions: Send Messages, Connect, Speak, Read Message History

انسخ الرابط الناتج وافتحه لدعوة البوت لسيرفرك.

### 3. تثبيت البرامج المطلوبة على جهازك
يحتاج البوت برنامج ffmpeg مثبت على النظام:

- ويندوز: حمّل ffmpeg من https://ffmpeg.org وضف مساره الى PATH
- ماك: `brew install ffmpeg`
- لينكس: `sudo apt install ffmpeg`

### 4. تثبيت مكتبات بايثون
```
pip install -r requirements.txt
```

### 5. اضافة التوكن
افتح ملف `bot.py` وضع التوكن الذي نسخته مكان:
```python
TOKEN = "ضع_التوكن_هنا"
```

### 6. تشغيل البوت
```
python bot.py
```

بعد التشغيل ادخل اي روم صوتي واكتب في الشات مثلا:
```
!play اسم الاغنية
```
أو
```
!شغل رابط الاغنية
```

## ملاحظات
- يجب ان تكون داخل روم صوتي حتى يشتغل البوت
- يمكنك تغيير الرمز `!` الذي يسبق الاوامر من متغير بيئة اسمه `BOT_PREFIX` او من متغير `PREFIX` في اعلى الملف
- البوت يدعم قائمة انتظار تلقائية، فاذا كتبت play وانت مشغل مقطع بيضاف للقائمة

## رفع البوت على Railway

الملفات التالية جاهزة مسبقا لهذا الغرض:
- `Procfile` يخبر Railway كيف يشغل البوت
- `nixpacks.toml` يخبر Railway انه يحتاج تثبيت ffmpeg
- `requirements.txt` لتثبيت المكتبات

### الخطوات

1. سوي حساب على https://railway.app وربطه بحساب Github لديك

2. ارفع مجلد المشروع (bot.py, requirements.txt, Procfile, nixpacks.toml) الى مستودع Github جديد
   ```
   git init
   git add .
   git commit -m "بوت اغاني ديسكورد"
   git branch -M main
   git remote add origin رابط_المستودع_تبعك
   git push -u origin main
   ```

3. من لوحة تحكم Railway اضغط New Project ثم Deploy from Github repo واختر المستودع الي رفعته

4. بعد ما ينشئ المشروع روح لتبويب Variables واضف متغير بيئة جديد
   - الاسم: `DISCORD_TOKEN`
   - القيمة: التوكن تبع البوت (نفسه الي نسختوه من Discord Developer Portal)

   يمكنك اضافه متغير اختياري كمان
   - الاسم: `BOT_PREFIX`
   - القيمة: الرمز الي تبيه يسبق الاوامر، مثلا `!`

5. Railway بيسوي بناء ونشر تلقائي بعد اضافه المتغيرات، تاكد من تبويب Deployments انه انتهى البناء بنجاح

6. من تبويب Settings تاكد ان نوع الخدمة Worker مو Web، لان البوت لا يحتاج فتح منفذ ويب
   اذا ظهرت رسالة انه Railway يتوقع فتح بورت تجاهلها، لان البوت يشتغل بالخلفيه فقط بدون خادم ويب

7. راقب اللوقز (Logs) من نفس الصفحة، اذا شفت رسالة تسجيل الدخول باسم البوت فهذا يعني انه اشتغل بنجاح

### تنبيه مهم بخصوص التوكن
لا ترفع التوكن مباشره داخل الكود على Github ابدا، الكود الحالي مصمم بحيث يقرا التوكن من متغير بيئة `DISCORD_TOKEN` وليس من داخل الملف، هذا يحميك من سرقة التوكن اذا كان المستودع عام
